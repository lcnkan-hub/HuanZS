一、项目概况
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  寰中枢 是一个移动端优先的 Vue 3 个人知识库 App。
  纯前端 SPA，零后端依赖；AI 聊天直连 DeepSeek API。

  技术栈：
    · Vue 3 (Composition API + <script setup>)
    · Vite 5 构建工具
    · 纯 CSS (CSS Variables 主题体系)
    · localStorage 持久化 (百科数据/聊天/记忆)
    · IndexedDB (图片仓库，避开 5MB 上限)
    · Capacitor 8 (Android 打包)

  页面结构 (底部 Tab 导航)：
    ┌──────────┬──────────┬──────────┬──────────┬──────────┐
    │ 🎮 游戏  │ 📝 笔记  │ 🍀 生活  │ 👑 王冠  │ 👤 我的  │
    └──────────┴──────────┴──────────┴──────────┴──────────┘
    (王冠 Tab 为全屏聊天界面，隐藏底部导航)

  启动方式：
    cd F:\寰中枢
    npm install          # 首次
    npm run dev          # 启动开发服务器
    npm run test:crisis  # 危机系统测试 (改危机结构必跑)

三、文件清单与职责
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ┌─────────────────────────────────────────────────────────┐
  │ 3.1  项目根文件                                          │
  └─────────────────────────────────────────────────────────┘

  package.json
    项目元信息 + 依赖声明。
    依赖: vue@3.4, vite@5, @capacitor/*@8, pngjs。
    命令: dev / build / preview / test:crisis。

  capacitor.config.json + android/
    Capacitor 8 配置 + Android 工程目录。

  scripts/ (run-crisis-tests.mjs / crisis.test.mjs / resolve-hook.mjs)
    危机响应系统 A/B/C/D 用例矩阵运行器。
    resolve-hook.mjs: ESM 解析钩子，让原生 node 解析无扩展名相对导入。

  CLAUDE.md / PROJECT.md / RULES.md / TASKS.md
    AI 协作文件：工作指引 / 技术规格 / 编码规范 / 开发路线图。

  ┌─────────────────────────────────────────────────────────┐
  │ 3.2  入口层 + 根组件                                     │
  └─────────────────────────────────────────────────────────┘

  src/main.js
    应用入口。createApp(App).mount('#app')，导入全局样式。

  src/App.vue
    根组件。职责：页面叠层编排 + 全局状态持有 + 王冠 Tab 调度。
    组装: SplashScreen / AppHeader / WikiList / WikiDetail
          / MinePage / ModalBox / BottomNav / ChatView
    持有: currentTab / searchQueries / openedItem / showAddModal
    逻辑: useUserProfile / useWikiData / usePageRouter

  ┌─────────────────────────────────────────────────────────┐
  │ 3.3  常量层 (constants/)                                 │
  └─────────────────────────────────────────────────────────┘

  categories.js
    分类配置中心。Tab/图标/分类/头像/存储键统一管理。
    导出: TAB_ICONS / TAB_NAMES / ALL_CATEGORIES / NAV_ITEMS
          / AVAILABLE_AVATARS / STORAGE_KEYS

  icons.js
    SVG 图标库。统一 viewBox=24 / stroke=2 / currentColor，
    含 <title> 无障碍标签，由 AppIcon.vue 渲染。

  crisis.js + crisisContextPatterns.js
    危机信号定义 + 上下文模式（危机子系统输入侧）。

  ┌─────────────────────────────────────────────────────────┐
  │ 3.4  工具层 (utils/)                                     │
  └─────────────────────────────────────────────────────────┘

  markdownParser.js
    Markdown 编译器。纯函数。
    支持: 标题/加粗/代码/颜色标签/图片引用 (id://img-xxx)。
    安全: 先全量 HTML 转义 → 局部安全还原。

  uniqueId.js
    ID 生成 + 时间格式化。generateUniqueId / getCurrentTimeString。

  ┌─────────────────────────────────────────────────────────┐
  │ 3.5  样式层 (styles/)                                    │
  └─────────────────────────────────────────────────────────┘

  variables.css
    CSS 变量体系（色彩/圆角/阴影/动画/间距/字体/尺寸）。

  ┌─────────────────────────────────────────────────────────┐
  │ 3.6  逻辑层 (composables/)                               │
  └─────────────────────────────────────────────────────────┘

  useLocalStorage.js
    本地持久化积木。deep watch 自动写入，异常静默处理。

  useUserProfile.js
    用户档案积木。首次自动生成 (6位ID + 用户名 + 头像)，updateProfile。

  useWikiData.js
    百科数据库积木。完整 CRUD + 搜索 + 导入导出校验。
    扩展: addChildItem / updateChildWiki / deleteChildItem (子词条)。

  usePageRouter.js
    页面路由积木。详情面板打开/关闭 + 叠层动画状态机 + 来源页恢复。

  useChat.js
    王冠聊天积木。消息增删 + localStorage 持久化 + 欢迎语。

  useChatAI.js
    王冠 AI 请求积木。DeepSeek API 调用 + 人格系统提示词 +
    危机管线短路 (命中即不走主 LLM)。

  useMemory.js
    王冠记忆积木。白名单四类写入 + 情绪打标状态机 + 沉默阈值 +
    C 档留门式开口 + 隐私话术 (情感依赖不落库 / 私密事件固定回应)。

  useImageStore.js
    图片存储积木。IndexedDB 仓库，saveImage / getImageUrl /
    deleteImage / dropUnused，生成持久 blob URL。

  ┌─────────────────────────────────────────────────────────┐
  │ 3.7  服务层 (services/)                                  │
  └─────────────────────────────────────────────────────────┘

  crisisDetection.js
    危机检测。五层管线检测层，识别直接表达/具体计划/告别/情绪突变。

  riskStateMachine.js
    风险状态机。状态迁移规则 (A/B/C 档位)。

  crisisResponse.js
    危机响应。接住情绪 → 识别信号 → 让位转介 (12356/120)，轻量确认。

  storageAdapter.js
    存储适配器。localStorage 读写；node 测试环境自动降级内存 Map。

  ┌─────────────────────────────────────────────────────────┐
  │ 3.8  组件层 (components/)                                │
  ├─────────────────────────────────────────────────────────┤
  │ 3.8.1  通用组件 (common/)                                │
  └─────────────────────────────────────────────────────────┘

  SplashScreen.vue   开屏动画。同会话只显示一次。
  AppIcon.vue        SVG 图标渲染 (name + size)。
  ModalBox.vue       通用弹窗 (default/actions 插槽)。
  HelloGuide.vue     欢迎引导页。

  ┌─────────────────────────────────────────────────────────┐
  │ 3.8.2  王冠组件 (crown/)                                 │
  └─────────────────────────────────────────────────────────┘

  ChatView.vue       王冠聊天页编排。全屏聊天 + 记忆查看入口。
  CrownEntrance.vue  王冠入场动画。夜晚「灯醒」/ 白天「光启」双模式。
  MemorySheet.vue    记忆查看面板。展示白名单四类记忆。

  ┌─────────────────────────────────────────────────────────┐
  │ 3.8.3  布局组件 (layout/)                                │
  └─────────────────────────────────────────────────────────┘

  AppHeader.vue      顶部搜索/添加栏。
  BottomNav.vue      底部导航栏。5 个 Tab (游戏/笔记/生活/王冠/我的)。

  ┌─────────────────────────────────────────────────────────┐
  │ 3.8.4  百科组件 (wiki/)                                  │
  └─────────────────────────────────────────────────────────┘

  WikiDetail.vue     详情页。子词条列表 + 添加/删除/编辑入口。
  SubEntryEditor.vue 子词条编辑器。阅读/编辑双模式 + 图片插入
                     + 缩略图预览 (最大组件)。
  WikiList.vue       列表页。分类标题 + 卡片列表 + 空状态引导。
  WikiCard.vue       单张百科卡片。

  ┌─────────────────────────────────────────────────────────┐
  │ 3.8.5  用户中心组件 (user/)                              │
  └─────────────────────────────────────────────────────────┘

  MinePage.vue          个人中心编排页。
  UserProfileCard.vue   用户名片 (头像 + 用户名 + 枢纽ID)。
  FootprintSummary.vue  创造力足迹统计。
  CategoryGroup.vue     分类条目折叠面板 (×3 复用)。
  DataBackup.vue        数据备份保险箱 (导出/导入/校验)。
  EditProfileModal.vue  修改资料弹窗。
