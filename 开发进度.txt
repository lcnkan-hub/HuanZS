一、项目概况
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  寰中枢 是一个移动端优先的 Vue 3 个人知识库 App。
  纯前端 SPA，零后端依赖，数据存储在浏览器 localStorage。

  技术栈：
    · Vue 3 (Composition API + <script setup>)
    · Vite 5 构建工具
    · 纯 CSS (CSS Variables 主题体系)
    · localStorage 持久化 (5MB 上限)

  页面结构 (底部 Tab 导航)：
    ┌──────────┬──────────┬──────────┬──────────┐
    │ 🎮 游戏  │ 📝 笔记  │ 🍀 生活  │ 👤 我的  │
    └──────────┴──────────┴──────────┴──────────┘

  启动方式：
    cd F:\寰中枢
    npm install     # 首次
    npm run dev     # 启动开发服务器

  ──────────────────────────────────────────
    cd F:\寰中枢
    npm run dev        启动开发服务器 (localhost:5173)
    npm run build      构建生产版本

  5.2  添加新分类
  ──────────────────────────────────────────
    只需修改 src/constants/categories.js：
      1. TAB_ICONS 加新 key
      2. TAB_NAMES 加新 key
      3. ALL_CATEGORIES 加新 key
      4. NAV_ITEMS 加新项
      5. STORAGE_KEYS.DB 初始值加新空数组
    即可 —— 所有组件自动适配。

  5.3  添加新功能 (积木规范)
  ──────────────────────────────────────────
    1. 业务逻辑 → 新建 src/composables/useXxx.js
    2. UI 组件  → 新建 src/components/xxx/Xxx.vue
    3. 配置数据 → 放在 constants/ 中
    4. App.vue 编排组装

  5.4  数据操作
  ──────────────────────────────────────────
    导出备份: 个人中心 → 导出全量数据备份
    导入恢复: 个人中心 → 导入备份恢复数据
    清除数据: 浏览器 DevTools → Application → Local Storage
